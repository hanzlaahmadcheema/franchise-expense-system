# Financial Ledger V2

## Principle

Ledger V2 separates editable facts from generated balances.

- Raw entries are the source of truth.
- Projections are generated by the calculation service.
- Legacy embedded arrays and subcollections are compatibility snapshots.

The required invariant is:

```text
Day N+1 opening = Day N closing
Month N+1 opening = Month N closing
```

## Firestore Paths

V2 additive paths:

```text
ledgerV2/{module}/months/{monthId}
ledgerV2/{module}/months/{monthId}/days/{dayNo}/rawEntries/{entryId}
ledgerV2/{module}/months/{monthId}/days/{dayNo}/projections/{projectionId}
ledgerV2/{module}/months/{monthId}/summary/{summaryId}
ledgerV2/{module}/months/{monthId}/calcRuns/{runId}
ledgerV2/{module}/months/{monthId}/mismatchReports/{reportId}
```

Preserved compatibility paths:

```text
months/{monthId}/days/{dayNo}
months/{monthId}/days/{dayNo}/credits/{creditId}
months/{monthId}/summary/home
jazzLoadMonths/{monthId}
stockMonths/{monthId}
stockBalances/...
```

Client writes are limited to `rawEntries`. Projection, summary, calc-run, and mismatch-report writes are server-owned.

## Expense Credit Flow

1. Autosave writes raw day facts and legacy compatibility data in one batch.
2. Raw credit entries are stored under `ledgerV2/expense/.../rawEntries`.
3. `recalculateMonth` writes verified `ledgerV2/expense/.../projections`.
4. If an invariant fails, a `mismatchReports` document and `BALANCE_MISMATCH_DETECTED` audit log are created.
5. The app shows an owner/admin warning until the mismatch report is repaired.

## Migration CLI

Dry-run and backup:

```bash
npm run ledger:dry-run:may2026
```

Generic use:

```bash
node scripts/ledger-v2-migration.mjs \
  --month 2026-05 \
  --dry-run \
  --output-report tmp/ledger-v2-2026-05-report.json \
  --backup-file tmp/ledger-v2-2026-05-backup.json
```

The script uses Firebase CLI authenticated REST reads. It does not print tokens and does not call `firebase login:list --json`.

Apply mode writes only `ledgerV2` paths and requires an explicit guard:

```bash
node scripts/ledger-v2-migration.mjs \
  --month 2026-05 \
  --apply \
  --confirm-apply-v2 \
  --output-report tmp/ledger-v2-2026-05-apply-report.json \
  --backup-file tmp/ledger-v2-2026-05-backup.json
```

Do not run apply before reviewing the backup and dry-run report.

## Rollback

Rollback is logical first:

1. Stop using V2 readers or projections.
2. Keep existing V1 paths untouched.
3. Re-run the app against preserved compatibility paths.

Only restore backup data in a separate Firebase project or emulator unless a production restore is explicitly approved.

```bash
npm test
npm run build

npm --prefix functions test
firebase deploy --only firestore:rules --dry-run
```

If Firebase CLI credentials are expired, reauthenticate before treating rules verification as complete.
